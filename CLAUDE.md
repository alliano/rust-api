# Project Rules

## Git Attribution (WAJIB)

Setiap commit message dan PR description di project ini **wajib** menyertakan trailer berikut:

```
Co-Authored-By: alliano <allianoanoanymous@gmail.com>
```

Ini berlaku bersamaan dengan attribution line default Claude Code, jadi commit/PR akan punya kedua trailer:

```
Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>
Co-Authored-By: alliano <allianoanoanymous@gmail.com>
```

Aturan ini tidak boleh dilanggar untuk commit/PR apapun di repo ini.
